# 拾光记账 (ShiGuang Ledger)

本地优先的移动端记账 PWA。先记账、后注册：游客数据存本机 IndexedDB，可导出备份，登录后迁移云端并多设备同步。

纯原生 HTML/CSS/JavaScript，零框架零依赖构建，Service Worker 全量预缓存，断网也能记账。

## 功能

- **记账**：明细 / 日历双视图、快捷记账、算式金额、常用备注记忆
- **统计**：环形占比、排行、年度热力图、资金流向、报表中心、财务健康度
- **预算**：月度总预算 + 信封式分类预算、超支预警、未来 30 天预测
- **资产**：净值趋势、多币种账户折算、信用卡管家、借入借出、债务清零计划、攒钱目标
- **智能**：AI 记账（文字 / 票据识别）、AI 问账、自动归类规则引擎、纠正记忆、待确认队列
- **数据**：JSON / 加密备份（PBKDF2 15 万轮 + AES-GCM）、CSV 导入导出（微信 / 支付宝账单）、共享账本（加密快照）、周期记账、多账本
- **形态**：PWA 可安装、微信内置浏览器与小程序 web-view 适配、深色模式、隐私遮罩

## 部署

整个仓库就是一个静态站点根目录，上传到任意静态托管（Cloudflare Pages / Vercel / GitHub Pages 等）即可运行。
云端同步依赖 `js/config.js` 里 workbuddy BaaS 的接入配置，按需替换。
