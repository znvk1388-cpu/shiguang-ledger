## 1. 第 0 步:前置(全部一次性)

1. **部署**:按 `site/README.md` 把官网 + App 部署到 HTTPS(Cloudflare Pages,约 20 分钟),拿到两个地址:
   - 官网地址(发货消息里放这个,买家从这里下载)
   - App 网页版地址(顺手让 iPhone 用户也能用)
2. **APK**:按 `site/twa-上架清单.md` 用 Bubblewrap 打包,把 APK 放到官网(或对象存储)拿到直链。
3. **签码工具**:确认 `D:\codex\workspace\backups\shiguang-ledger-license\` 私钥在;签一批码备用(见下)。
4. **建一本台账**:Excel/表格记录 `订单号 ↔ 激活码序号 ↔ 平台`,退款核销用。

签码示例(每单一条,--serial 从 1 开始递增):
```
node tools/license-sign.mjs --key "D:\codex\workspace\backups\shiguang-ledger-license\shiguang-pro-private-key.pem" --count 20 --serial 1
```
一次签 20 条存好,卖一条发一条。

## 2. 拼多多 SOP(第 1 周跑通第一单)

### 步骤 1:开店(30 分钟)
1. 手机应用商店装「拼多多商家版」→ 开店 → 选**个人店**(身份证原件照片 + 实人认证)。
2. **主营类目选「虚拟商品」**(必选对,选了实物类目后面上架会被卡)。
3. 手机号一号只能绑一家店;店铺名建议「拾光记账软件官方店」(一年内改名次数有限,起名想好)。
4. 用电脑网页版商家后台操作(别装电脑客户端,会和自动发货软件互相挤下线);手机商家版 App 只用来回消息。

### 步骤 2:缴保证金
- 后台「账户资金」→ 保证金:2026-08 新规**基础保证金 1000 元**;上架时如果类目弹额外保证金提示,先换一个不需要额外保证金的子类目试。

### 步骤 3:配自动发货(核心,半小时)
1. 商家后台「服务市场」搜「自动发货」(常见如阿奇索),订购(新店有试用期,按年更划算)。
2. 买一台入门云服务器(阿里云/腾讯云新用户一年几十元)把发货软件挂上去 24 小时运行——你的电脑关机它就停,半夜的单子就黄了。

### 步骤 4:上架商品
1. 「发布新商品」→ 虚拟商品大类下试选「软件/网络服务」相关子类目(系统弹保证金提示就换一个,以弹窗为准——**这是 SOP 里唯一需要现场试探的开关**)。
2. 标题(直接复制改):
   - `拾光记账Pro激活码 记账软件会员 AI智能记账 无广告 本机存储`
   - `拾光记账 记账本app激活码 手账理财AI记账 自动分类报表`
   - `拾光Pro激活码 记账软件 一年好用小工具 无订阅 买断`
3. 主图/详情:手机修图软件做——首图「拾光 Pro · ¥58 买断不订阅」;详情放 4–6 张:App 真实截图(可用 `npm run shots` 生成)+ 功能列表 + **激活三步**(买后自动发激活码→按消息里链接下载 App→「我的·拾光 Pro」粘贴激活)+ 售后声明(虚拟商品,激活码核销后不退换)。
4. 价格:¥49.9 起步跑量,有评价后调回 ¥58。

### 步骤 5:发货配置(照抄)
- 发货内容模板(粘进自动发货软件):
```
【拾光 Pro 激活码】{激活码}
① 下载 App:官网 https://你的域名(或直达 APK 链接)
② 打开 App →「我的」→「拾光 Pro」
③ 粘贴上方激活码 → 点「激活」即完成
激活遇到问题请直接回复本消息,客服在线 9:00-22:00。
```
- **顺序红线:先要卡券 → 先核销 → 再发货**。没核销平台视为未履约,订单会被自动退款。
- 卡券有效期设 7–15 天,别设一年(长有效期卡单会导致退店时保证金退不回)。

### 步骤 6:推广
- 虚拟类目自然流量少,靠付费:全站推广/搜索推广,「成交出价」按预期单均推广费设置(¥49.9 的品,先按 5–8 元成交出价测,跑 20–30 单看投产比再加减)。

### 拼多多红线(高频处罚点)
- 不诱导站外交易(消息里不要出现"加微信");下载链接给**官网域名**,不要给网盘/短链。
- 不承诺「永久更新」「终身」等绝对化词(反不正当竞争法 2025-10 新规把虚假宣传管得更严)。
- 详情页写明「虚拟商品:卡券核销后不支持无理由退货;激活失败包补发或退款」——写明比不写安全。
- 自研软件你是著作权人,无版权风险;但别在详情里蹭其他软件品牌词。

## 3. 小红书 SOP(第 1 天开始养,第 4–6 周挂车)

### 认清门槛(2026-02-10 新规)
虚拟产品(电子资源类目)要求:**粉丝 ≥1000、单月流水 ≥6000、入驻 ≥180 天、笔记 ≥30 篇、签合规承诺函**(审核实际重点看前三项)。开通"电子资源类目"的三选一条件里,**用拼多多店铺近 12 个月流水 ≥6000 也可以**(同主体=你本人身份证,拼多多个人店与小红书个人店主体一致,成立)。
所以小红书的节奏必然是:先养内容攒粉丝 → 用拼多多流水+粉丝数开类目 → 挂车。

### 阶段 A:第 1 天~第 2 周(养号 + 开店)
1. 「我」→ 左上角三杠 → 创作中心 → 开通店铺 → 个人店(身份证+人脸);开店费 0,保证金约 1000 可后补。
2. 账号校准:
   - 昵称:`拾光记账 | 一个人的记账软件研究所` 这类「身份+领域」结构
   - 简介:`做了个无广告的记账 App,数据只存自己手机里;分享记账方法和存钱实战`
   - 置顶两篇:一篇「新手记账从哪开始」干货,一篇产品真实使用记录
3. 发 **15–20 篇不挂车笔记**(内容模板见下),别刚开店就发广告。

### 阶段 B:第 3–6 周(冲 1000 粉 → 开类目 → 挂车)
1. 每 2 天 1 篇笔记,30 篇笔记门槛同步满足。
2. 粉丝过 1000 后:「店铺管理 → 品牌类目资质 → 更新资质」提交:小红书/拼多多流水截图 + 承诺函(个人店信用代码写「无」、法人签字)→ 1–3 个工作日审核。
3. 通过后上架商品(¥58),笔记挂车成交;自动发货同样可接阿奇索类工具。

### 笔记模板 ×3(直接照搬换数字)
1. **实测型**:`我让 AI 替我记了一个月账,发现钱都花在这 3 个地方`——配 App 报表截图,结尾一句「软件叫拾光记账,无广告,核心功能免费」
2. **挑战型**:`无支出日挑战第 14 天:我用「破戒不清零」的笨办法存下了 xx 元`——App 无支出日卡截图
3. **对比型**:`测了 5 个记账 App,最后留下的是这个没有广告的`——截图对比表,讲清"数据只存本机"差异点

### 小红书红线
- 不私信导流微信/QQ(封号重灾区);购买全部走店铺。
- 不用「最」「第一」等极限词;AI 生成图主动标注;不刷粉不互赞(平台 2025 封了 1200 万虚假账号)。
- 笔记像用户不像商家:「像个真实用户比像个专业商家重要」。

## 4. 抖音 SOP(个体户下来后;先做免费引流)

### 阶段 0:现在就能做(不挂车)
- 用个人抖音号发短视频(和上面 3 个笔记模板同选题),主页简介写「软件在官网/各商店搜 拾光记账」——**不要**在评论或私信里发链接、喊"加微信"。
- 这是零成本测内容:哪条脚本数据好,以后挂车就用哪条。

### 阶段 1:办个体工商户(线上,免费)
- 各地"一网通办/企业登记在线"全程线上申请;经营范围勾「软件开发、信息技术服务、技术服务」;拿到执照后微信「电子营业执照」小程序领电子照。
- 网络经营场所申请:有网店/店铺即可作为经营场所证明。

### 阶段 2:开抖店 + 虚拟权限
1. fxg.jinritemai.com 用**个体工商户**身份开店(自然人店现已基本不开放),缴保证金。
2. 虚拟商品走「虚拟业务/三方卡券」:注册抖音开放平台拿 appkey → 填表开权限(约 3–5 个工作日)→ 按接口对接发卡;类目归属「教育培训/知识服务」类需资质,「软件工具」类以后台试选提示为准。
3. 短视频挂小黄车 + 直播挂车;发货消息模板与拼多多一致(激活码+下载链接+激活三步)。

### 抖音红线
- 站外引流话术管控最严:任何视频/评论/私信都别出现微信号、二维码。
- 虚拟商品同样声明「核销后不退换」;直播口播别承诺「永久」。

## 5. 售后话术模板(三平台通用)

- 激活失败:`麻烦您把收到的激活码原样发我,我这边核验后 10 分钟内给您补发新码;若确认无效,可直接申请退款。`
- 退款政策:激活码**未核销**的全额退;已核销的因虚拟商品特性不支持无理由退货(详情页已声明),激活质量问题包补发。
- 差评处理:只解决问题,不做好评返现(三平台都在严打虚假评价)。
