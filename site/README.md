# 拾光记账 · 官网与直发上线清单（路径 A）

本目录是官网静态站（纯 HTML/CSS，无依赖）。目标：一周内把「APK 下载 + 激活码售卖」跑起来。

## 目录

- `index.html` 首页（下载入口 + Pro 介绍 + FAQ）
- `privacy.html` 隐私政策 / `agreement.html` 用户协议（商店审核与官网都要用）
- `twa-上架清单.md` TWA 打包 APK 的完整步骤

## 上线前必须替换的占位（全部已标注注释）

| 位置 | 占位 | 替换为 |
|---|---|---|
| index.html 下载按钮 | `#`（APK 直链） | TWA 打包产出的 APK 托管直链 |
| index.html 网页版按钮 | `#` | App 的 PWA 部署地址（HTTPS） |
| index.html 购买按钮 | `#` | 淘宝/爱发电商品链接 |

| repo `js/config.js` | `APP_INFO.operator/contact/siteUrl` | 真实主体、邮箱、官网地址 |

## 部署步骤（Cloudflare Pages，免费，约 20 分钟）

1. 注册 Cloudflare → Pages → 直接上传本目录（或连 Git 仓库）。
2. 绑定域名（如 shiguangji.com；域名购买后先把 DNS 指过去）。
3. **App 本体也托管**：把 repo 的静态产物（index.html + css/js/assets 等）部署到同一域名的子路径或独立域名，拿到 HTTPS 地址——TWA 打包与「网页版」按钮都指向它。
4. 替换上面清单里的占位链接。

## 售卖（激活码自动发货）

1. **软著**：现在就去中国版权保护中心提交登记（免费），材料=申请表+前后各 30 页源代码+说明文档；这是国内一切上架的门票，与官网直售可并行。
2. **收款**：二选一起步——
   - 淘宝/微店上架「拾光 Pro 激活码」虚拟商品，用平台的自动发货放卡密（平台费率约 5%）；
   - 或爱发电/面包多上架数字商品。
3. **发货内容**：用 `tools/license-sign.mjs` 按订单序号签发激活码（`--serial` 对应订单号，方便退款核销）。签发命令与私钥保管见 repo 内该工具头部注释。
