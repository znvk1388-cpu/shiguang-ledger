# 细节优化与验收（2026-11-13）

基线 v1.19.1（8e8ba8d），本轮版本 v1.19.2。沿用蓝色品牌、系统中文字体、现有图标和原生 JS/CSS，没有新增依赖。

## 改动与实际对比

| 细节 | 修改前 | 修改后 |
|---|---|---|
| 切到统计页 | 保留上页滚动，实测停在231–635px | 新页面从0开始；应用内刷新保留位置 |
| 快速重复点击 | 第二次点击可能取消尚未执行的回顶 | 保留待执行意图，仅最终渲染回顶 |
| 设置入口 | DIV，不能Tab聚焦 | 原生button，Enter/空格可用，关闭面板回到入口 |
| 分组标题 | 可点击高度31.5px | 最小44px，焦点与按压反馈清晰 |
| 设置分组 | 应用内刷新后自动合拢 | 本次会话保留用户展开/收起选择 |
| 慢设置请求 | 可能覆盖已切换的页面或身份 | 提交前核对容器、身份、页签及最新请求 |
| 平板弹层 | 顶角16px、底角0 | 居中弹层四角16px；手机底抽屉保留底边形态 |
| 备份提示 | data URL、持久化授权等技术术语；云端图片范围易误解 | 简洁说明保护状态与实际备份范围，云端凭证原图需另存 |

预算入口提供aria-expanded/aria-controls；输入框具有明确名称，展开后可直接输入。设置按钮保留列表视觉，统一对齐、分隔线和卡片内焦点环。
