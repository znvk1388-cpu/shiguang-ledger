# 海外商业与开源记账对标

核验日期为 2026-11-07。样本覆盖 4 款海外商业产品和 5 款开源产品，重点比较记一笔、找一笔、改一笔和批量处理。证据来自官方帮助、官方发布记录或项目源码。表格只记录资料可确认的路径，未登录账号、安装实测或测量耗时。官方资料未说明的平台差异与功能细节均未核验。

## 拾光现有能力和优先事项

本地 v1.18.11 的明细已经有关键字、收支类型、账户、标签、金额区间、空结果清理和本机常用筛选。统计可带分类跳转明细，分类和账户已有可见控件。高级筛选折叠后，标签和金额只通过漏斗图标状态体现，用户需要重新打开面板才能知道剩下哪些条件。可沿用现有筛选状态，让已生效标签、区间等在列表附近显示，提供清除按钮并保留账本和期间。已有隐私模式需要继续保护筛选中显示的具体金额，触屏和键盘都应可操作。[拾光筛选渲染与现有常用筛选](../js/ui.js) · [Actual 的账户账簿](https://actualbudget.org/docs/tour/accounts/)

拾光已有软删除、回收站和游客及云端恢复入口。若推进删除后的即时撤销，优先复用恢复接口，至少验证待处理期间切换账本或数据源、重复点击、写入失败和刷新后的恢复行为。新增跨设备撤销历史、整批导入回滚、分账及原账关联退款均超出简单界面改进，需要专门定义事务边界与统计口径。[拾光游客恢复](../js/guest-store.js) · [拾光云端恢复](../js/store.js) · [YNAB Web 删除说明](https://support.ynab.com/en_us/how-to-edit-and-delete-transactions-BJG4oS1s?mobile-help=true)
