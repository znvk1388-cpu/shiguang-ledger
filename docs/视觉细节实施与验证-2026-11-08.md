# 视觉细节实施与验证

日期：2026-11-08。基线为 GitHub main `b780dced864455cbb262ed0e95144df269bd5c05`（v1.18.13），本轮版本 v1.18.14。

## 设计与复用

对照钱迹、iCost、Copilot、Monarch、Actual 的官方静态界面图，复用拾光的原生 HTML/CSS/JavaScript、系统字体、蓝色品牌、SVG 导航和用户分类图标。[资料与观察边界](视觉对标-2026-11-07.md)。没有移植竞品源码或图片，也未增加运行时依赖。

## 具体改动

- 标题集中表达当前位置，删除重复口号和英文装饰；标题与金额减少混杂字重。
- 普通卡片去掉双层阴影，统一为 8/12/16px 圆角；筛选工具使用留白分组，分类图标减少内外多层边框。
- 备注与账户字号由 11px 提升到 13px，金额等宽、右对齐；深浅主题的选中项使用可读的品牌文字色。
- 分类用描边、淡底和勾选共同表达选中；数字键盘的完成按钮保持收起作用，保存保持主要操作。
- 首页预算保留已花/总额与进度；超支或预算使用率超过当月时间进度 10 个百分点时显示一条提示；统计页保留完整分析。
- 列表和日历共用流水容器裁切圆角；交易行焦点环向内绘制，避免被容器裁掉。
- 色盲配色保持中性内容底色，收入橙色提高文字对比度。
