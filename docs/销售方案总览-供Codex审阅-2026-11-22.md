## 1. 产品是什么

**拾光记账**:个人记账 App,纯原生 JavaScript PWA——无构建、无框架、无第三方运行时依赖(仅 PapaParse,MIT),数据默认存设备本机(IndexedDB),**无广告、无跟踪、不订阅**。

- 核心功能:记账、日历视图、年度热力图、收支统计、预算(月/分类/结转)、多账本、共享账本(加密快照)、周期记账(自动补记)、订阅/固定支出追踪、借入借出与债务清零、信用卡管家、攒钱目标、报销与对账、凭证相册、文件柜、JSON/CSV 导入导出、加密备份、应用锁、回收站、批量编辑。
- **拾光 Pro(付费)**:当前唯一 Pro 权益是 AI 智能记账(拍小票/一句话自动建账,走平台 LLM 网关,有真实调用成本);其余全部免费。
- 质量现状:**280 项自动化回归测试全通过**(jsdom + 真实 Chrome 冒烟),PWA 离线可用,微信小程序 web-view 环境已适配,Android 触感反馈,深色模式,无障碍标签齐全。
- 平台限制:iPhone 上暂为网页版(PWA 可添加到主屏);触感反馈仅 Android。

## 2. 商品与商业模式

| 项 | 内容 |
|---|---|
| 商品形态 | 「拾光 Pro」激活码(数字卡密),一次性**买断**,不订阅不自动扣费 |
| 当前权益 | AI 智能记账;后续新权益随版本更新免费加入 |
| 定价 | 官网/小红书/抖音 **¥58**;拼多多 **¥49.9** 跑量(待评估) |
| 激活机制 | 激活码 `SJ1.<载荷>.<签名>`:Ed25519 签名,**私钥只在卖家本机**(仓库外保管),公钥内置前端;WebCrypto 本机验证,不联网、不绑账号;状态存本机并随应用内备份迁移;粘贴自动激活 |
| 防伪逻辑 | 前端代码全部公开也伪造不出激活码;代价是**无服务器吊销**——一个码被多人共用只能靠序号对账事后处理 |
| 发货 | 全渠道统一模板:激活码 + 官网下载链接 + 「我的 → 拾光 Pro」粘贴激活三步 |
| 售后口径 | 核销后不支持无理由退货(虚拟商品,详情页声明);无法激活凭购买凭证补发 |
| 边际成本 | 记账功能 ≈ 0;仅 AI 调用与平台费率 |

## 5. 开卖前的硬前置(全部待办,均已明确路径)

- [ ] **部署 HTTPS**(Cloudflare Pages,约 20 分钟)→ 填 `js/config.js` 的 `APP_INFO.siteUrl` → 按 `site/twa-上架清单.md` 用 Bubblewrap 打 APK → 官网挂下载与购买链接
- [ ] **GitHub 仓库转私有**(售卖前防抄)
- [ ] **软著登记**(中国版权保护中心,官方免费,30–40 工作日,个人可办)——国内上架的硬门票,越早提交越好
- [ ] ICP 备案 + App 备案(苹果中国区上架也强制要求备案号)
- [ ] 个体工商户(线上免费办理;解锁抖音/小程序/官方收款)
- [ ] 运营主体信息填真实值(`js/config.js` 的 `APP_INFO`,现在仍是占位值,商店审核逐字核对)

## 6. 合规红线汇总(所有渠道通用)

1. 卡券核销顺序不能反;卡券有效期设 7–15 天,别设一年(影响退店退保证金)
2. 不诱导站外交易(不发微信/QQ;下载链接给自有官网域名,不给网盘/短链)
3. 不用「永久」「最」等绝对化用语(反不正当竞争法 2025-10 新规)
4. 虚拟商品「核销后不退换」必须在详情页显著声明;激活失败包补发
5. 版权:全部代码自研(唯一第三方库 PapaParse 为 MIT);不蹭其他记账软件品牌词
6. 小红书:AI 生成内容要标注、不刷粉不互赞、笔记要像用户不像商家
7. 引流阵地(豆瓣/B站等)先分享后提工具,不硬广

## 8. 请 Codex 重点审阅的 9 个问题

1. **定价**:¥58 买断(对标 iCost)对「无广告+本机存储」的记账工具是否最优?首发期该不该更低(¥39.9)换评价?拼多多 ¥49.9 与其他渠道 ¥58 的价差是否会造成比价客诉?
2. **Pro 权益单薄问题**:只有「AI 记账」一个权益是否撑得起 ¥58 买断?要不要把「报表海报导出」「多账本」「加密备份」也划入 Pro?划入会不会伤害现有免费用户口碑?(产品仓库是公开的,老用户已在免费使用)
3. **渠道优先级**:拼多多(货架+搜索)先于小红书(内容+人群匹配)的顺序是否正确?有没有被忽略的、对「个人开发者+记账工具」更高效的渠道?
4. **激活机制风险**:无服务器吊销的买断激活码,共码/盗卖风险的实际大小?行业里个人开发者怎么处理(激活次数上限?设备指纹?)?在不引入服务器的前提下有什么轻量缓解?
5. **合规遗漏**:上述红线清单之外,卖软件激活码还有哪些容易踩的坑(电商法、广告法、平台虚拟商品细则、发票义务)?
6. **文案合规**:下面这段商品标题是否安全,怎么改更好:`拾光记账Pro激活码 记账软件会员 AI智能记账 无广告 本机存储`
7. **个体户**:注册时机(现在 vs 首单之后)、经营范围怎么写(软件开发/信息技术服务?)、对后续收款(支付宝微信官方支付 0.6%)与各平台开店的连带影响?
8. **微信小程序取舍**:个人主体虚拟支付已开放但 web-view 受限——是「先做原生重写小程序」还是「等个体户走 web-view」还是「放弃小程序」?
9. **首发 30 天行动**有没有更优排序?当前计划:部署 → 拼多多开店上架 → 闲鱼/酷安/爱发电同步 → 小红书养号 → 软著申请。
