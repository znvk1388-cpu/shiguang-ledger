## 二、卖货的完整链路(谁都能照做)

1. 签激活码:`node tools/license-sign.mjs --key <私钥路径> --count 20 --serial <起始订单号>` → 输出 SJ1. 激活码
2. 发货消息模板:激活码 + 官网下载链接 + 激活三步(见 SOP)
3. 买家在 App「我的 → 拾光 Pro」粘贴激活(粘贴自动激活)
4. 台账记录:订单号 ↔ 序号 ↔ 平台(退款核销用)

## 三、发版流程(每次改代码后)

1. 改 `package.json` + `js/app.js` 的 `VERSION` + `README.md` 版本行 + 写 `更新说明-vX.Y.Z.md`
2. `npm run stamp`(盖 sw 缓存章,不改会挂)
3. `npm test` 全量回归(当前 278 项)
4. `npm run smoke`(需先起 `python -m http.server 4174`,需 Chrome)
5. 商品截图:`npm run shots`(加 `--demo` 种演示数据)
6. `git commit` + `git push origin main`
