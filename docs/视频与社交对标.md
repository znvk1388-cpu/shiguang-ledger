# 拾光记账｜视频调研与产品对比

核查日期：2026-10-29。以下 YouTube 来源只获取到公开标题、描述与章节，**没有播放视频或取得逐字稿**，因此不能断言画面中的具体操作；实际功能以产品官方文档及拾光源码复核。只参考交互思路，不复制源码。

## 新用户首次使用

- [FULL ActualBudget Tutorial | Budgeting Never Got Easier](https://www.youtube.com/watch?v=DTw4GwuY0jE)：公开视频描述将首次建预算、添加账户、记第一笔、查看预算/报表/周期列为入门流程。它由第三方发布，说明反映作者的教程安排，不能代表项目官方建议。
- [Actual Budget 官方产品导览](https://actualbudget.org/docs/tour/)解释预算、账户流水、周期和规则之间的关系。
- 拾光 `js/ui.js` 已有首次使用引导，入口包括记第一笔、设预算和查看示例；`js/legal.js` 有使用帮助。应优先验证新用户能否理解每步效果及游客数据位置，而非重复创建一套引导。

## 对账的可解释性

- [Reconciling in YNAB: A Step-by-Step Guide](https://www.youtube.com/watch?v=qMQ7dUHuzIM) 的公开视频标题和章节显示主题为对账步骤与对账频率；未查看画面或逐字稿。
- [Actual Budget 官方对账说明](https://actualbudget.org/docs/accounts/reconciliation/)区分已核对、未核对流水及其余额。拾光已提供逐笔核对标记和余额校准；当前核对标记只在本机，余额校准会修改期初余额并影响历史，不能与完整跨设备对账混为一谈。
- 可继续改进：在对账开始、结果和余额校准前解释适用范围；明确本机标记不随设备同步，并让用户先处理缺失或重复流水。具体设计须考虑跨币种和账本口径。

## 导入核对

- [Actual Budget 官方导入说明](https://actualbudget.org/docs/transactions/importing/)介绍导入交易与手工交易匹配和重复检查；不意味着其匹配规则适合中国平台账单。
- 拾光现有微信/支付宝 CSV、疑似重复逐笔复核及同账本候选对照。可结合真实脱敏账单继续验证同金额多笔、退款、不同账户和跨月边界，不要自动覆盖或合并原记录。
