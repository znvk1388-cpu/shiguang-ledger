# 动效与操作手感

日期：2026-11-09。基线 v1.18.15，main `9c084dc4f3b0a970b5ef6a00fed91325ebc0f1e4`；本轮 v1.18.16。

## 设计与复用

延续现有蓝色、系统字体和界面结构，直接复用 CSS 过渡与浏览器 Web Animations API，无新增运行时依赖。动画只回答用户操作；账目写入与界面可用性不等待动画结束。[MDN Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API/Using_the_Web_Animations_API) · [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

| 反馈 | 节奏与实现 |
| --- | --- |
| 按下与松开 | 按下约70ms轻缩，松开约180ms复位；图标、普通按钮与键盘使用适合自身尺寸的幅度 |
| 页面与视图切换 | 用户切换后180ms、4px以内的短反馈；普通数据刷新不重新播放页面过渡 |
| 面板 | 进入240ms、离开180ms；已打开面板的内容替换只做140ms透明度过渡，保留居中定位 |
| 保存 | 写入等待时显示静态文案、禁用和aria-busy；正常模式有小型旋转指示，成功后显示勾选 |

同一表面新反馈取消旧反馈，结束后清理动画引用。开启系统减少动态效果会取消当前脚本动效，后续非必要位移跳过，按压不再缩放，加载图标保持静态；列表/日历切换和输入纠错滚动也遵守该设置。浏览器不支持动画API时，已完成的内容直接可用。

成功勾选只在账目及本次附加操作没有待核对事项时显示；保存失败恢复按钮、清除忙碌状态并保留输入，部分凭证上传失败不展示成功勾选。
