# 拾光记账视觉对标

核对日期：2026-11-07；拾光代码观察基线为本轮视觉调整前的 v1.18.13。沿用蓝色品牌、中文普通用户与原生感 PWA 定位。这份笔记补充既有功能对标，重点看官方公开静态界面图中的排版、层级、表面、分隔、颜色和图标；未安装或登录竞品，不能据此判断完整流程、动效、真实设备字号和无障碍质量。

## 优先落实的三项

1. **把阅读层级做清楚。** 明细中让分类或交易名与右侧金额成为第一层，日期、账户、备注成为第二层。保留拾光已有的等宽数字和金额右对齐；账户、备注等有用信息可从调整前的 11px 提高到 12.5–13px，正文试用 14–15px，金额保留约 16px。这里是给拾光的试用值，并非从竞品测出的字号。先用中文长备注、六位金额和空备注比较，避免所有文本同时加粗。钱迹的日标题与日总计、Monarch 的交易行都能看到明确的两端对齐与轻重区别。[钱迹官方图](https://res.qianjiapp.com/qianji_feature_v6_001_960.png) · [Monarch 官方交易图](https://cdn.sanity.io/images/mdewiujj/production/ac4492258662072fc45e5638f21ac55e42199e1e-1689x1188.png)
2. **普通内容靠留白和细线分组。** 拾光调整前的 `.card` 同时有边框和双层阴影，优先把普通卡片阴影收轻或去掉；弹层仍可用阴影表达浮起。每日账目维持一组连续白色表面，行间用细分隔，不把每条记录装进独立悬浮卡片。iCost 的表单组与 Monarch 的流水图体现了两种不同用途：输入项分组、账目连续排列。白色表面、浅灰页底和现有蓝色足够建立秩序。[iCost 官方导入图](https://help.icostapp.com/assets/img/import_01.c8185b9c.jpeg) · [Monarch 官网来源页](https://www.monarch.com/)
3. **限制颜色的职责，保留图标分工。** 蓝色用于主要动作与选中状态；收支色表达业务；中性文字承担普通内容。拾光已经有统一描边 SVG 导航，继续复用即可；用户分类 emoji 可以保留，并统一容器、对齐及底色浓度。Copilot、Monarch 的官方图确实使用 emoji，因此不能把 emoji 本身判断为“AI 模板感”。优先减少无业务含义的强调色、重复徽章与装饰，让有状态的元素才突出。[Copilot 官方图](https://www.copilot.money/img/home/hero/screen-clean.webp) · [Monarch 官方图](https://cdn.sanity.io/images/mdewiujj/production/ac4492258662072fc45e5638f21ac55e42199e1e-1689x1188.png)

以上尺寸和取舍属于结合拾光代码的设计建议，不是竞品的明文设计规范。现有系统字体、等宽数字、蓝色令牌和图标资源均可复用，无需引入新的 UI 框架或整套主题。

## 复用与验收边界

这轮先查既有产品与开源方案，再复用拾光自己的令牌、图标和列表实现。Actual 为开源项目，但本轮没有移植其源码；其他产品的截图、商标与专有界面仅用于内部对照，不进入拾光产品资源，也不改造成竞品皮肤。[Actual 官方仓库与许可证](https://github.com/actualbudget/actual)

落地后应在同一份示例数据、相同尺寸和主题下对照前后画面：先看金额与交易名，再读日期、账户和备注；检查长内容不抢位、辅助文字仍可读、普通卡片与弹层层次不同。至少覆盖 390px 手机与 1280px 桌面，另复查 320px、深色和大号文字。本文没有进行这些实现后的验收，也没有下载或逐帧观看视频。
